# 화면 스타일 가이드

Vision Monitor의 화면과 공통 컴포넌트는 기능 구현뿐 아니라 컴포넌트 내부의 여백, 정렬, 크기 계층까지 함께 검토한다. 특정 화면에서만 보이는 임의의 간격값을 추가하기 전에 공통 컴포넌트의 기준을 먼저 확인한다.

## 공통 간격 원칙

- 텍스트는 부모 경계선에 붙이지 않는다. 최소 좌우 `12px`, 주요 헤더와 버튼은 `16px` 이상의 내부 여백을 기본으로 한다.
- 아이콘은 주변 텍스트와 같은 시각적 높이를 가지도록 크기와 터치 영역을 함께 조정한다. 아이콘만 키우거나 버튼만 키우지 않는다.
- 인접한 선택 요소는 서로 붙여 배치하지 않는다. 같은 수준의 탭과 버튼은 최소 `8px` 간격을 둔다.
- 컴포넌트의 좌우 여백, 내부 패딩, 요소 사이 간격을 각각 구분해서 확인한다. 한 값을 키워 다른 간격을 대신하지 않는다.
- 테두리와 콘텐츠 사이에 충분한 여백을 두고, 콘텐츠가 테두리에 시각적으로 붙어 보이지 않는지 실제 화면 크기에서 확인한다.

## 계층형 탭

- 상위 탭과 하위 탭은 같은 글자 크기와 높이를 사용하지 않는다.
- 상위 탭은 선택 영역으로서 활성 상태를 분명하게 표현하고, 하위 탭은 더 낮은 밀도와 대비로 표현한다.
- 두 탭 영역은 좌우 기준선을 맞추되, 각 탭 사이 간격과 텍스트 주변 여백을 별도로 확보한다.
- 탭 이름, 삭제 아이콘, 추가 아이콘이 서로 붙거나 특정 요소만 과도하게 커지지 않도록 하나의 행 기준으로 정렬한다.

## 영상 타일

- 영상 타일 헤더는 상태 표시, 영상 제목, 확대보기 아이콘의 세 영역으로 보고 간격을 함께 조정한다.
- 제목은 헤더 좌우 테두리에서 떨어져 있어야 하며, 긴 제목은 레이아웃을 밀어내지 않고 말줄임 처리한다.
- 확대보기 아이콘은 헤더 높이에 맞는 시각적 크기를 사용하고, 아이콘 버튼의 오른쪽 끝에도 여백을 둔다.
- 재생 컨트롤은 타일의 외곽 테두리에 바로 붙이지 않는다. 타일 내부에 여백을 두고 떠 있는 컨트롤 패널로 표현한다.
- 컨트롤 패널의 재생바, 버튼, 볼륨 조절 영역도 패널 내부에서 균일한 간격을 유지한다.

## 검토 체크리스트

- [ ] 텍스트가 부모 요소의 테두리나 다른 요소에 붙어 보이지 않는가?
- [ ] 같은 수준의 버튼과 탭 사이에 일관된 간격이 있는가?
- [ ] 제목과 아이콘의 크기, 수직 정렬, 터치 영역이 균형을 이루는가?
- [ ] 작은 타일과 넓은 타일 모두에서 제목이 겹치거나 잘리지 않는가?
- [ ] 다크 테마와 라이트 테마에서 여백과 계층이 동일하게 유지되는가?
- [ ] CSS 수치 하나만 조정하지 않고 부모 패딩, 형제 간 간격, 콘텐츠 크기를 함께 확인했는가?
