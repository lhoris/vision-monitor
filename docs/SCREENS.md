### 1.6 드래그 & 드롭 (재배치)

#### 기능
- **Source**: 기존 카메라 셀
- **Target**: 다른 셀 (비어있거나 다른 카메라)
- **결과**: 
  - 비어있는 셀 드래그 → 카메라 이동
  - 다른 카메라 셀에 드롭 → 교환 (또는 기존 카메라 제거)

#### React DnD 구현 예시
```typescript
// frontend/src/components/layout/CameraGrid.tsx
const CameraGrid: React.FC<CameraGridProps> = ({ layoutId }) => {
  const [cameras, setCameras] = useState<CameraPosition[]>([]);
  
  // 드래그 시작
  const handleDragStart = (e: React.DragEvent, cameraId: number) => {
    e.dataTransfer.effectAllowed = 'move';
    e.dataTransfer.setData('cameraId', String(cameraId));
  };
  
  // 드롭
  const handleDrop = async (e: React.DragEvent, cellId: number) => {
    e.preventDefault();
    const draggedCameraId = parseInt(e.dataTransfer.getData('cameraId'));
    
    // Backend API로 순서 변경 요청
    await layoutApi.reorderCameras(layoutId, {
      draggedCameraId,
      targetCellId: cellId
    });
    
    // UI 업데이트
    setCameras(updatedCameras);
  };
  
  return (
    <div className="camera-grid">
      {cameras.map((camera, idx) => (
        <div
          key={camera.cellId}
          onDrop={(e) => handleDrop(e, camera.cellId)}
          onDragOver={(e) => e.preventDefault()}
        >
          {camera.camera_id ? (
            <CameraCell
              camera={camera}
              draggable
              onDragStart={(e) => handleDragStart(e, camera.camera_id)}
            />
          ) : (
            <AddCameraCell cellId={camera.cellId} />
          )}
        </div>
      ))}
    </div>
  );
};
```

### 1.7 자동 저장

#### 저장 메커니즘
- **트리거**:
  1. 카메라 추가/제거 (자동)
  2. 그리드 크기 변경 (자동)
  3. 드래그 & 드롭 완료 (자동)
  4. 사용자가 [💾 저장] 버튼 클릭

- **Backend API**:
  ```typescript
  PUT /api/layouts/:id
  Body: {
    tab_name: "공정 A (냉각)",
    grid_config: { rows: 3, cols: 2, type: "3x2" },
    camera_positions: [
      { cell_id: 0, camera_id: 1, position: { row: 0, col: 0 } },
      { cell_id: 1, camera_id: 2, position: { row: 0, col: 1 } },
      // ...
    ]
  }
  ```

- **저장 피드백**:
  - 토스트 알림: "레이아웃이 저장되었습니다"
  - 상태 표시기: 저장 중 → 저장됨 (체크마크)

### 1.8 사용자별 레이아웃 영속성

#### 다음 접속 시 복원
1. 사용자 로그인
2. Frontend: `GET /api/layouts` (사용자별 저장된 레이아웃 조회)
3. 마지막으로 접속한 탭 자동 선택 (is_default = true인 레이아웃)
4. 해당 탭의 그리드 및 카메라 배치 로드

#### 데이터베이스 스키마
```sql
CREATE TABLE layout (
  id INT PRIMARY KEY AUTO_INCREMENT,
  user_id INT NOT NULL,
  tab_name VARCHAR(100) NOT NULL,
  grid_config JSON NOT NULL,  -- {"rows": 3, "cols": 2, "type": "3x2"}
  camera_positions JSON NOT NULL,  -- [{"cell_id": 0, "camera_id": 1, "position": {"row": 0, "col": 0}}, ...]
  is_default BOOLEAN DEFAULT FALSE,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  
  FOREIGN KEY (user_id) REFERENCES user(id),
  INDEX idx_user_default (user_id, is_default)
);
```

### 2.3 Timeline Scrubber (시간 선택)

#### 기능
- **날짜 선택**: 캘린더 위젯 (`react-datepicker`)
- **시간 스크러버**: 24시간 타임라인
- **이벤트 마커**: 
  - 🔴 적색: 심각도 높음
  - 🟠 주황: 심각도 중간
  - 🟡 노랑: 심각도 낮음
- **속도 조절**: 1x, 2x, 4x, 10x
- **재생 제어**: 이전/다음 프레임, Play/Pause/Stop

#### 구현 (React + Recharts)
```typescript
// frontend/src/components/timeline/TimelineScrubber.tsx
const TimelineScrubber: React.FC = () => {
  const [selectedDate, setSelectedDate] = useState<Date>(new Date());
  const [events, setEvents] = useState<TimelineEvent[]>([]);
  const [playbackSpeed, setPlaybackSpeed] = useState(1);
  
  // 시간 변경 시 녹화 파일 및 이벤트 로드
  const handleTimeChange = async (time: string) => {
    const [hours, minutes] = time.split(':').map(Number);
    const timestamp = new Date(selectedDate);
    timestamp.setHours(hours, minutes, 0);
    
    // Backend: 해당 시간대 이벤트 조회
    const eventList = await eventApi.getEventsByTime(
      cameraId,
      timestamp,
      new Date(timestamp.getTime() + 3600000)  // +1시간
    );
    setEvents(eventList);
  };
  
  return (
    <div className="timeline-scrubber">
      <DatePicker selected={selectedDate} onChange={setSelectedDate} />
      <TimelineChart events={events} onTimeChange={handleTimeChange} />
      <PlaybackControls speed={playbackSpeed} onSpeedChange={setPlaybackSpeed} />
    </div>
  );
};
```
