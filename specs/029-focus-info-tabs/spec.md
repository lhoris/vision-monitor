# 기능 명세서: 화면 확대 보기 정보 탭

**기능 브랜치**: `029-focus-info-tabs`
**작성일**: 2026-11-20
**상태**: 초안

## 1. 기능 요약

화면 확대 보기의 우측 정보 영역을 `모델기본정보`와 `알람 이력` 탭으로 구성한다. 실시간 화면에서는 모델기본정보를 기본 탭으로 보여주고, 녹화 화면에서는 알람 이력을 기본 탭으로 보여준다. 사용자는 현재 화면 모드와 관계없이 두 탭을 직접 전환할 수 있다.

## 2. 기능 요구사항

- **FR-001**: 시스템은 화면 확대 보기 우측 정보 영역에 모델기본정보 탭과 알람 이력 탭을 제공해야 한다.
- **FR-002**: 실시간 화면으로 진입하거나 실시간 모드로 전환하면 모델기본정보 탭을 기본 선택해야 한다.
- **FR-003**: 녹화 화면으로 진입하거나 녹화 모드로 전환하면 알람 이력 탭을 기본 선택해야 한다.
- **FR-004**: 사용자는 현재 모드와 관계없이 두 탭을 클릭하여 직접 전환할 수 있어야 한다.
- **FR-005**: 모델기본정보 탭은 현재 영상 소스에 연결된 모델기본정보 섹션과 기존 편집 기능을 그대로 제공해야 한다.
- **FR-006**: 알람 이력 탭은 현재 카메라에 연결된 알람 목록을 발생 시각, 제목, 심각도로 표시하고 선택 상태를 제공해야 한다.
- **FR-007**: 알람 이력의 알람을 선택하면 기존 알람 선택 흐름을 사용하여 상세정보와 녹화 타임라인의 해당 시점 이동이 동작해야 한다.
- **FR-008**: 알람 이력이 없으면 사용자가 목록이 비어 있음을 알 수 있는 안내를 표시해야 한다.
- **FR-009**: 알람 이력 조회에 실패하면 모델기본정보 탭 사용을 방해하지 않고 알람 이력 영역에 오류 안내를 표시해야 한다.
- **FR-010**: 탭 이름과 안내 문구는 한국어와 영어 번역을 제공해야 한다.

## 3. 범위 제외

- 알람 이력 데이터의 저장 구조, 조회 API, 알람 확인 처리 정책은 이번 기능에서 변경하지 않는다.
- 알람 이력의 검색, 필터, 페이징, 정렬 기능은 이번 범위에 포함하지 않는다.
- 실시간 알람 수신 방식과 모델기본정보 섹션 설정 방식은 변경하지 않는다.

## 4. 사용자 시나리오 및 테스트

### 사용자 스토리 1 - 모드별 기본 정보 탭 확인 (P1)

실시간 화면 사용자는 진입 즉시 모델기본정보를 확인하고, 녹화 화면 사용자는 진입 즉시 알람 이력을 확인할 수 있다.

1. **Given** 화면 확대 보기에서 실시간 모드로 진입했을 때, **When** 우측 정보 영역이 표시되면, **Then** 모델기본정보 탭이 선택되어야 한다.
2. **Given** 화면 확대 보기에서 녹화 모드로 진입했을 때, **When** 우측 정보 영역이 표시되면, **Then** 알람 이력 탭이 선택되어야 한다.
3. **Given** 모드가 변경되었을 때, **When** 화면이 새 모드로 전환되면, **Then** 해당 모드의 기본 탭으로 전환되어야 한다.

### 사용자 스토리 2 - 탭 직접 전환 및 기존 기능 유지 (P1)

사용자는 기본 탭과 관계없이 필요한 정보 탭을 직접 선택할 수 있다.

1. **Given** 실시간 모드에서 모델기본정보 탭이 선택되어 있을 때, **When** 알람 이력 탭을 클릭하면, **Then** 알람 이력 탭의 내용이 표시되어야 한다.
2. **Given** 녹화 모드에서 알람 이력 탭이 선택되어 있을 때, **When** 모델기본정보 탭을 클릭하면, **Then** 기존 모델기본정보 섹션과 편집 기능이 표시되어야 한다.
3. **Given** 모델기본정보 탭에서 섹션을 추가·편집·삭제할 때, **When** 기존 저장 흐름을 수행하면, **Then** 기존과 동일하게 동작해야 한다.

### 사용자 스토리 3 - 알람 이력에서 녹화 위치 이동 (P1)

녹화 화면 사용자는 알람 이력에서 알람을 선택하여 해당 시점의 녹화 영상을 확인할 수 있다.

1. **Given** 알람 이력 목록이 표시될 때, **When** 알람을 클릭하면, **Then** 해당 알람이 선택되고 기존 상세정보가 갱신되어야 한다.
2. **Given** 녹화 화면에서 알람을 선택했을 때, **When** 알람 선택 흐름이 완료되면, **Then** 녹화 재생 구간과 타임라인이 해당 알람 시점을 기준으로 이동해야 한다.
3. **Given** 알람 목록이 비어 있거나 조회에 실패했을 때, **When** 알람 이력 탭을 열면, **Then** 적절한 빈 상태 또는 오류 안내가 표시되고 모델기본정보 탭은 계속 사용할 수 있어야 한다.

## 5. UI/UX 요구사항

- 탭은 우측 정보 영역 상단에 배치하고 선택 상태를 시각적으로 구분한다.
- 기본 탭은 모드 변경 시 자동으로 바꾸되, 사용자의 탭 클릭을 막지 않는다.
- 알람 이력 목록은 기존 녹화 알람 목록과 동일한 선택·키보드 접근성을 유지한다.
- 탭 전환 시 영상 영역의 크기와 재생 상태는 변경하지 않는다.
- 탭 이름, 빈 상태, 오류 문구는 현재 선택 언어를 따른다.

## 6. 성공 기준

- **SC-001**: 실시간 모드 진입 시 모델기본정보가 첫 화면에 표시되고, 녹화 모드 진입 시 알람 이력이 첫 화면에 표시된다.
- **SC-002**: 사용자는 두 번의 클릭 이내에 두 정보 탭 사이를 전환할 수 있다.
- **SC-003**: 알람 이력에서 알람을 선택하면 기존 알람 선택·녹화 이동 흐름이 정상 동작한다.
- **SC-004**: 탭 기능 추가 후 모델기본정보 편집 기능과 녹화 영상 재생 기능의 기존 테스트가 모두 통과한다.

## 7. 가정

- 현재 카메라 이벤트 조회와 알람 선택 흐름을 재사용하며 새로운 저장 모델이나 API는 추가하지 않는다.
- 실시간 모드의 알람 이력은 현재 조회 범위에서 제공되는 데이터가 없을 수 있으며, 이 경우 빈 상태를 표시한다.
- 탭 상태는 화면 모드 변경 시 모드별 기본값으로 초기화하고, 별도 사용자별 영구 저장은 하지 않는다.
