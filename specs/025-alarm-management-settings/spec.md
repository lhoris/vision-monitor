# 기능 명세서: 통합 알람 관리

## 1. 목적

관리자가 알람 유형별 기본 저장·수신·채널·수신자·확인 범위를 관리하고, 사용자별 예외 수신 설정을 지정한다.

## 2. 핵심 요구사항

- 알람 분류는 일반 알람과 모델 알람으로 구분한다.
- 알람 유형별 정책은 `TB_M26_ALARM_RULE`에서 관리한다.
- `TB_M26_CODE_DETAIL`에는 알람 정책 컬럼을 추가하거나 사용하지 않는다.
- 수신자는 전체 관리자 또는 지정 사용자로 설정할 수 있다.
- 확인 범위는 사용자별 확인 또는 공동 확인으로 설정할 수 있다.
- Push(SSE), 메일, Teams 수신 여부를 기본값과 사용자별 예외값으로 설정할 수 있다.
- 알람 로그 저장 여부를 알람 유형별로 설정한다.
- 공동 확인 알람은 한 수신자가 확인하면 동일 `ALARM_GROUP_ID`의 모든 수신자 로그를 확인 처리한다.

## 3. 적용 우선순위

사용자별 설정이 있으면 사용자별 설정을 우선하고, 없으면 `TB_M26_ALARM_RULE`의 기본 정책을 사용한다. 알람 로그 저장과 SSE 전송은 각각 독립적으로 판단한다.

## 4. 범위

이번 범위는 알람 관리 화면, 알람 규칙·사용자별 예외 API, 회원가입 요청 알람, SSE 수신, 알람 확인 처리까지다. 실제 메일·Teams 발송 연동은 후속 범위로 둔다.

## 5. 성공 기준

- 관리자가 전용 알람 규칙 화면에서 정책을 조회·수정할 수 있다.
- 회원가입 요청 알람이 규칙과 사용자별 설정에 따라 로그 저장 및 SSE 전송된다.
- 공동 확인과 사용자별 확인이 설정값에 따라 구분 동작한다.
- 공통코드 상세 테이블에는 알람 정책 컬럼이 남지 않는다.
