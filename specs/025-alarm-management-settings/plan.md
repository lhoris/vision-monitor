# 구현 계획: 통합 알람 관리

## 기술 방향

- 기존 Spring Boot/JPA, 공통코드, 사용자 권한, SSE 구조를 재사용한다.
- 새 테이블 없이 `TB_M26_CODE_DETAIL`, `TB_M26_USER_ALERT_PREF`, `TB_M26_ALARM_LOG`를 확장한다.
- 관리자 화면은 기존 `AdminPlaceholder` 라우팅과 Sidebar 패턴에 추가한다.
- 메일/Teams는 정책 저장과 조회까지만 구현하고 실제 발송 어댑터는 후속 범위로 둔다.

## 단계

1. 정책 컬럼과 사용자 예외 컬럼을 엔티티, migration, DTO에 반영한다.
2. 관리자 전용 통합 조회/저장 API를 제공한다.
3. 가입 요청 알람에 수신자·push·로그·공동확인 그룹 정책을 적용한다.
4. 알람 확인 API에 공동/개별 확인 범위를 적용한다.
5. 한 화면에 유형 정책과 사용자별 수신자·채널 설정 UI를 구현한다.
6. 테스트와 빌드로 기존 알람 회귀를 확인한다.
