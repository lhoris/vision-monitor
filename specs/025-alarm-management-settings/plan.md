# 구현 계획: 통합 알람 관리

## 기술 방향

- 알람 유형별 기본 정책은 전용 `TB_M26_ALARM_RULE`과 JPA `AlarmRule`로 관리한다.
- `TB_M26_CODE_DETAIL`은 공통코드 데이터만 담당하며 알람 정책 컬럼을 포함하지 않는다.
- 사용자별 수신·채널 예외는 기존 `TB_M26_USER_ALERT_PREF`, 발생 이력과 확인 상태는 기존 `TB_M26_ALARM_LOG`를 사용한다.
- SSE는 기존 `AlarmEventPublisher`를 유지하고, 규칙에 따라 수신 대상과 push 여부만 결정한다.

## 구현 순서

1. 기존 공통코드 상세의 알람 정책 데이터를 전용 규칙 테이블로 이관하는 `V035` 마이그레이션을 추가한다.
2. `AlarmRule` 엔티티와 저장소를 연결하고 알람 관리 조회·수정 서비스를 전환한다.
3. 회원가입 알람 발행과 알람 확인 범위 판정을 `AlarmRule` 기반으로 전환한다.
4. 공통코드 스키마와 설계서를 정리하고 백엔드 테스트 및 빌드를 수행한다.
