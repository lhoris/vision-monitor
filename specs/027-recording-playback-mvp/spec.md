# 기능 명세서: 화면 확대 보기 녹화 재생 MVP

**기능 브랜치**: `027-recording-playback-mvp`

**작성일**: 2026-11-17

**상태**: 초안

**변경 추적**: 문서 변경 이력은 Git 커밋 이력을 기준으로 한다.

**입력**: 사용자 설명: "실제 녹화 영상 URL을 기준으로 화면 확대 보기의 녹화 탭에서 start/end를 조작해 재생하고, 알람을 클릭하면 해당 구간을 재생한다."

> 이 문서는 한국어로 작성한다. 기술 용어, API 이름, 파일 경로, 코드 식별자는 원문 또는 영문 표기를 유지할 수 있다.

> **기능 개요 - Agent 요약**
>
> 화면 확대 보기의 녹화 탭에서 사용자는 원하는 시작·종료 시각을 지정해 녹화 영상을 조회하고 재생할 수 있다. 녹화 영상은 현재 MVP에서 검증용 `video6` 재생 경로를 사용한다. 알람 정보를 선택하면 알람 발생 시각 전후의 구간이 자동으로 구성되어 해당 녹화 위치를 확인할 수 있다. 현재 구현은 MVP 검증을 위해 단일 녹화 서버와 단일 영상 경로를 대상으로 하며, 이후 영상별 녹화 경로 관리로 확장할 수 있다.

## 2. 기능 요구사항

### 기능 요구사항

- **FR-001**: 사용자는 화면 확대 보기에서 실시간 보기와 녹화 보기를 구분해 선택할 수 있어야 한다.
- **FR-002**: 녹화 보기에서 사용자는 녹화 시작 시각과 종료 시각을 지정해 영상을 조회할 수 있어야 한다.
- **FR-003**: 시스템은 지정된 시간 구간을 기준으로 녹화 영상을 재생해야 한다.
- **FR-004**: 사용자는 플레이어 하단의 메인 녹화 타임라인과 영상 재생바를 이용해 현재 조회된 녹화 구간 안에서 재생 위치를 이동할 수 있어야 한다.
- **FR-005**: 사용자가 화면 확대 보기의 알람 정보를 선택하면 시스템은 알람 발생 시각 전후의 녹화 구간을 구성하고 해당 위치를 재생해야 한다.
- **FR-006**: 시스템은 녹화 영상 조회 중 로딩, 녹화 없음, 잘못된 시간 범위, 재생 실패 상태를 사용자가 이해할 수 있는 메시지로 표시해야 한다.
- **FR-007**: 녹화 재생은 현재 선택된 카메라/영상과 연결된 상태에서 수행되어야 하며 실시간 보기 흐름을 방해하지 않아야 한다.

## 3. 제외 범위

- 이번 MVP에서는 영상 관리 화면에서 녹화 서버 기본 주소와 영상별 `recording_path`를 편집하는 기능을 구현하지 않는다.
- 이번 MVP에서는 여러 녹화 서버, 여러 영상 ID, 영상별 동적 녹화 경로를 일반화하지 않는다.
- 이번 MVP에서는 녹화 서버의 사용자명·비밀번호 관리 화면, 운영용 비밀 저장소, 인증 프록시를 구현하지 않는다.
- 이번 MVP에서는 실제 Spring Boot 녹화 API와 DB migration을 추가하지 않고 검증용 재생 계약을 사용한다.
- 녹화 파일 저장, 녹화 정책 설정, 다운로드, 모바일 최적화는 제외한다.

## 4. UI/UX 요구사항

- **UX-001**: 녹화 탭에는 시작 시각과 종료 시각을 한 영역에서 확인·수정할 수 있는 입력부와 조회/재생 동작이 제공되어야 한다.
- **UX-002**: 조회 중에는 중복 요청을 방지하고 로딩 상태를 표시해야 한다.
- **UX-003**: 영상 플레이어는 현재 조회된 구간 안에서 기본 재생바를 제공해야 한다.
- **UX-007**: 메인 녹화 타임라인은 녹화 가능 구간, 현재 재생 위치, 알람 marker를 시각적으로 구분하고 마우스 클릭과 방향키로 재생 위치를 이동할 수 있어야 한다.
- **UX-004**: 알람 선택으로 자동 조회된 경우 사용자가 알람 시각을 중심으로 재생 중임을 알 수 있어야 한다.
- **UX-005**: 녹화 영상이 없거나 재생할 수 없는 경우 빈 화면 대신 한국어 안내 메시지를 표시해야 한다.
- **UX-006**: 기존 실시간 탭의 영상 재생과 카메라 전환 동작은 변경하지 않아야 한다.

## 5. 필요한 정보

- 선택된 카메라/영상 식별자
- 녹화 영상 재생 경로
- 녹화 조회 시작 시각과 종료 시각
- 현재 재생 가능한 구간과 재생 위치
- 알람 식별자, 발생 시각, 관련 카메라/영상
- 녹화 조회 및 재생 결과 상태

## 6. 사용자 시나리오 및 테스트

### 사용자 스토리 1 - 시간 구간을 지정해 녹화 영상 재생 (우선순위: P1)

운영자는 화면 확대 보기에서 녹화 탭을 선택하고 시작·종료 시각을 지정해 해당 시간의 영상을 확인한다.

**관련 기능 요구사항**: FR-001, FR-002, FR-003, FR-004, FR-006, FR-007

**이 우선순위인 이유**: 녹화 탭의 기본 가치이며, 알람 연계 없이도 독립적으로 검증할 수 있는 MVP 핵심 흐름이다.

**독립 테스트**: 검증용 `video6`를 대상으로 시작·종료 시각을 지정하고 조회하면 영상 플레이어가 표시되며, 재생바로 조회 구간 안의 위치를 이동할 수 있는지 확인한다.

**수용 시나리오**:

1. **Given** 화면 확대 보기에서 카메라 영상이 선택된 상태, **When** 사용자가 녹화 탭을 선택하면, **Then** 녹화 시간 입력과 녹화 조회 영역이 표시된다.
2. **Given** 유효한 시작·종료 시각, **When** 사용자가 녹화를 조회하면, **Then** 해당 구간의 녹화 영상이 플레이어에 표시된다.
3. **Given** 녹화 영상이 표시된 상태, **When** 사용자가 기본 재생바를 조작하면, **Then** 조회된 구간 안에서 재생 위치가 변경된다.
4. **Given** 종료 시각이 시작 시각보다 빠르거나 같은 상태, **When** 사용자가 조회하면, **Then** 조회 요청 없이 시간 범위 오류가 표시된다.

---

### 사용자 스토리 2 - 알람에서 관련 녹화 구간으로 이동 (우선순위: P2)

운영자는 화면 확대 보기에서 알람을 선택해 알람 발생 전후의 녹화 영상을 바로 확인한다.

**관련 기능 요구사항**: FR-005, FR-006, FR-007

**이 우선순위인 이유**: 알람 원인 확인 시간을 줄이는 핵심 업무 흐름이지만, 기본 녹화 재생이 먼저 제공되어야 검증할 수 있다.

**독립 테스트**: 녹화 탭에서 알람 정보를 선택하면 알람 시각을 포함하는 시간 구간이 자동 설정되고 플레이어가 해당 위치에서 재생되는지 확인한다.

**수용 시나리오**:

1. **Given** 선택된 카메라와 연결된 알람 정보, **When** 사용자가 알람을 선택하면, **Then** 알람 시각 전후의 녹화 조회 구간이 자동 구성된다.
2. **Given** 자동 구성된 유효한 구간, **When** 녹화 영상이 조회되면, **Then** 플레이어는 알람 발생 시각에 해당하는 위치를 기준으로 표시한다.
3. **Given** 알람과 연결된 녹화가 없는 상태, **When** 사용자가 알람을 선택하면, **Then** 녹화 없음 또는 재생 불가 안내가 표시되고 화면이 깨지지 않는다.

### 엣지 케이스

- 시작 시각과 종료 시각이 없거나 형식이 잘못된 경우 조회하지 않고 안내한다.
- 조회 구간이 지나치게 긴 경우 MVP에서 허용하는 최대 구간을 넘었다는 안내를 표시한다.
- 녹화 서버가 응답하지 않거나 영상 재생이 실패하면 현재 영상 대신 재생 실패 상태를 표시한다.
- 카메라 전환 또는 실시간 탭 전환 중 이전 녹화 요청이 늦게 도착해도 현재 선택과 무관한 영상으로 교체하지 않는다.
- 선택한 알람의 카메라가 현재 화면의 카메라와 다르면 해당 알람을 현재 녹화 플레이어에 적용하지 않는다.

## 7. 성공 기준

### 측정 가능한 결과

- **SC-001**: 사용자는 화면 확대 보기에서 3회 이내의 조작으로 녹화 영상을 조회할 수 있다.
- **SC-002**: 유효한 검증용 구간을 조회했을 때 5초 이내에 플레이어 또는 명확한 오류 상태가 표시된다.
- **SC-003**: 사용자는 현재 조회 구간 안에서 기본 재생바로 재생 위치를 이동할 수 있다.
- **SC-004**: 알람 선택 시 알람 발생 시각을 포함한 녹화 구간이 자동 설정되고, 사용자는 알람 위치를 확인할 수 있다.
- **SC-005**: 잘못된 시간 범위나 녹화 불가 상황에서 사용자는 원인을 나타내는 한국어 안내를 확인할 수 있다.
- **SC-006**: 기존 실시간 탭의 재생과 카메라 전환 테스트가 기존 수준으로 통과한다.

## 8. 가정 및 미정 사항

### 가정

- MVP 검증 대상 녹화 경로는 `/playback/video6.mp4`이다.
- 녹화 URL은 지정된 시작·종료 시각을 query parameter로 전달하는 방식이다.
- 알람 자동 재생 구간은 알람 발생 시각 기준 앞뒤 30초로 한다.
- MVP에서는 녹화 서버 인증정보를 프론트엔드 코드에 직접 저장하지 않고 검증용 재생 계약/adapter로 캡슐화한다.
- 기존 화면 확대 보기의 녹화 컴포넌트와 테스트 구조를 우선 재사용한다.

### 미정 사항

- 없음. 실제 운영 연동에 필요한 녹화 서버 인증·주소·영상별 경로 관리는 후속 기능으로 분리한다.
