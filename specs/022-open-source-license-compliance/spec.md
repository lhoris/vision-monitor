# 오픈소스 라이선스 고지 명세

## 목적

운영 배포물에 포함되는 백엔드와 프론트엔드 오픈소스 의존성을 식별하고, 라이선스와 저작권 정보를 배포 시 함께 제공한다.

## 요구사항

- 백엔드 Maven 런타임 의존성과 프론트 npm 운영 의존성을 인벤토리로 관리한다.
- 테스트 전용 의존성은 운영 고지 목록과 분리한다.
- 각 항목에 이름, 버전, 라이선스, 저작권/출처 정보를 기록한다.
- Apache, EPL, LGPL, GPL with Classpath Exception 등 라이선스 원문 또는 공식 URL을 함께 제공한다.
- 고지 파일은 운영 배포 디렉토리와 프론트 정적 산출물에 포함될 수 있어야 한다.
- 의존성이 변경되면 동일한 생성 명령으로 고지 목록을 갱신할 수 있어야 한다.
- 라이선스가 확인되지 않은 항목은 생성 실패 또는 별도 검토 목록으로 분류한다.

## 비범위

- 라이선스 법률 해석 또는 배포 가능 여부의 최종 판단
- 오픈소스 의존성 교체

## 완료 기준

- 자동 생성 스크립트가 백엔드와 프론트 의존성 목록을 생성한다.
- `licenses/THIRD-PARTY-NOTICES.md`가 생성되고 배포 스크립트에서 복사할 수 있다.
- 생성 결과에 라이선스 미확인 항목이 명시된다.
- 문서에 법무 검토가 필요한 EPL/LGPL/GPL 계열 항목이 표시된다.

## 조치 결과

- `scripts/generate-oss-notices.ps1`가 Maven 런타임 의존성과 npm 운영 의존성을 수집한다.
- `licenses/THIRD-PARTY-NOTICES.md`에 171개 패키지의 이름, 버전, 라이선스, 출처를 생성했다.
- 확인되지 않은 라이선스는 `LEGAL REVIEW`로 표시한다.
- `scripts/build.bat`가 빌드 완료 전에 고지 문서를 생성한다.
- `scripts/deploy.bat`가 고지 문서를 `deploy/licenses`에 복사한다.
