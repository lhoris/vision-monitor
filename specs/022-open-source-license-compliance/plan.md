# 오픈소스 라이선스 고지 계획

1. 현재 배포 구조와 Maven/npm 의존성 위치를 확인한다.
2. 의존성 메타데이터를 수집하는 PowerShell 스크립트를 추가한다.
3. 런타임 의존성과 테스트/개발 의존성을 구분한다.
4. 라이선스별 주의사항과 공식 URL을 포함한 고지 문서를 생성한다.
5. 배포 스크립트가 고지 파일을 backend/frontend 산출물에 복사하도록 연결한다.
6. 생성 결과와 빌드를 검증한다.

생성 결과는 법무 검토용 인벤토리이며, 최종 배포 허용 여부는 회사 법무/오픈소스 정책으로 확인한다.

## 검증 결과

- 고지 생성 스크립트 실행 성공
- 171개 운영 의존성 인벤토리 생성
- 기존 백엔드 테스트와 프론트 빌드 결과 유지
