# 확인 취소 검증 절차

1. 백엔드를 실행하고 로그인한다.
2. 알람 화면에서 확인 완료 필터를 선택한다.
3. 확인 완료 알람의 `확인 취소`를 누르고 확인 창에서 확인한다.
4. 성공 토스트를 확인하고 상태 필터를 미확인으로 전환한다.
5. 우측 상단 알람 벨의 미확인 건수와 목록에 해당 알람이 다시 표시되는지 확인한다.
6. 공동 확인으로 설정된 알람을 확인 취소한 경우 같은 그룹의 수신자 알람도 미확인으로 복원되는지 확인한다.

## 자동 검증

- `mvn -q -Dtest=AlarmControllerTest test`
- `npm run build`
