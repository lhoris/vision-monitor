# 온보딩 투어 동작 보완 명세

## 목적

기존 `024-guided-onboarding` 명세의 초기 구현 범위를 현재 구현 및 사용자 검증 결과에 맞게 보완한다. 온보딩은 사용자의 실제 화면 조작을 유도하되, 사용자가 다음 단계 버튼만 눌러도 막힘없이 진행되어야 한다.

## 공통 원칙

- 온보딩은 도움말 아이콘을 클릭했을 때만 시작한다.
- 온보딩 진행 중에는 업무 화면의 기존 기능과 데이터 구조를 변경하지 않는다. 단, 라이브 화면의 영상 추가처럼 사용자가 확인할 수 있는 실제 UI 동작은 다음 단계 진행을 위해 자동 실행할 수 있다.
- 모든 동적 대상은 실제 DOM에 나타난 뒤 다음 단계로 이동한다.
- 단계 재진입 시 이전 단계에서 등록한 이벤트 감시기를 먼저 정리한다. 동일한 클릭 한 번으로 단계가 두 번 진행되어서는 안 된다.
- 한국어와 영어 문구를 모두 제공하며, 한국어 환경에서는 한국어 문구를 우선한다.

## 라이브 대시보드 투어

라이브 투어 단계는 다음 순서를 따른다.

1. 공정 탭을 설명한다.
2. 세부공정 탭을 설명한다.
3. 빈 그리드 영역과 영상 추가 방법을 설명한다.
   - 사용자가 빈 영역을 클릭하면 영상 추가 팝업을 열고 다음 단계로 이동한다.
   - 사용자가 클릭하지 않고 `다음`을 누르면 빈 영역 클릭을 자동 실행하고 영상 추가 팝업을 연다.
4. 영상 소스 선택 방법을 설명한다.
   - 사용자가 영상 소스를 클릭하면 영상이 추가되고 다음 단계로 이동한다.
   - 사용자가 클릭하지 않고 `다음`을 누르면 선택 가능한 첫 번째 영상 소스를 자동 선택한다.
   - `이전`을 누르면 영상 추가 팝업을 닫고 3단계로 돌아간다.
5. 영상과 그리드 배치를 설명한다.
   - `이전`을 누를 때 빈 영역이 있으면 영상 추가 팝업을 다시 열고 4단계로 이동한다.
   - 빈 영역이 없으면 이전 단계로 이동하지 않고 현재 단계에 머문다.
6. 영상 타이틀바의 우클릭 기능을 설명한다.
   - 사용자가 타이틀바를 실제로 우클릭하면 우클릭 메뉴 단계로 이동한다.
   - 사용자가 우클릭하지 않고 `다음`을 누르면 우클릭 이벤트를 자동 실행하고 메뉴가 렌더링된 뒤 다음 단계로 이동한다.
7. 영상 우클릭 메뉴에서 이름 변경, 플레이어 영역 변경, 영상 제거를 설명한다.
   - 메뉴 단계에서 `이전` 또는 `다음`으로 이동하면 열린 메뉴를 닫는다.
8. 그리드 레이아웃 버튼을 설명한다.
   - 사용자가 레이아웃 버튼을 직접 클릭해 목록을 열어도 9단계로 자동 이동한다.
   - `다음`을 누르면 레이아웃 목록을 자동으로 열고 목록이 렌더링된 뒤 9단계로 이동한다.
   - `이전`을 누르면 영상 우클릭 메뉴를 다시 열고 7단계로 이동한다.
9. 펼쳐진 그리드 레이아웃 목록에서 프리셋 및 사용자 지정 행·열을 설명한다.
   - `이전` 또는 `완료`로 이동하면 레이아웃 목록을 닫는다.

라이브 투어에는 알람 기능 설명 단계를 포함하지 않는다.

## 탐색 및 단축키

- `다음 ›` 버튼은 다음 단계로 이동한다.
- `‹ 이전` 버튼은 이전 단계로 이동한다.
- Driver.js 기본 키보드 동작을 사용한다.
  - `ArrowRight`: 다음 단계
  - `ArrowLeft`: 이전 단계
  - `Escape`: 투어 종료
- 단계별 팝업·메뉴의 열림과 닫힘은 버튼, 방향키, 실제 사용자 조작 경로에서 동일하게 처리한다.

## 동적 대상 처리

- 영상 소스 목록, 영상 우클릭 메뉴, 그리드 레이아웃 목록처럼 초기 화면에 존재하지 않는 요소는 `waitForElement`로 렌더링을 기다린다.
- 동적 대상 단계는 대상이 렌더링되기 전에 앞 단계가 마지막 단계로 판단되지 않도록 한다.
- 대상이 존재하지 않는 경우에는 실제 업무 화면을 임의로 변경하지 않는다.
- 투어 종료, 화면 이동, 재시작 시 등록된 전역 이벤트 감시기와 Driver.js 인스턴스를 정리한다.

## 검증 기준

- 라이브 투어를 `다음` 버튼만으로 끝까지 진행할 수 있다.
- 영상 타이틀바 우클릭과 영상 소스 선택을 직접 수행해도 동일한 단계 순서로 진행된다.
- 이전 이동 시 팝업과 메뉴가 단계에 맞게 닫히거나 다시 열린다.
- 영상 소스 선택 후 5단계를 건너뛰지 않는다.
- 레이아웃 기본 단계의 버튼이 동적 메뉴 단계가 준비되기 전에 `완료`로 표시되지 않는다.
- 온보딩 단위 테스트와 프론트엔드 빌드가 통과한다.
