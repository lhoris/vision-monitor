# 온보딩 범위 확장

## 목적

로그인과 라이브 대시보드에 한정했던 단계별 안내를 인증 후 전체 화면으로 확장한다. 초기 확장에서는 화면별 핵심 목적과 공통 이동·알람 기능만 안내하고, 상세 업무 흐름은 화면별 후속 요구사항으로 고도화한다.

## 대상 화면

- 화면 확대 보기
- 녹화 영상 재생
- 알람 목록
- 알림 설정
- 영상 관리
- 사용자 관리
- 공통코드 관리
- 쿼리 관리
- 모델 관리
- 기타 관리자 화면

## 초기 안내 원칙

- 도움말 아이콘을 클릭했을 때만 시작한다.
- 사이드 메뉴, 현재 화면의 목적, 알람 벨을 기본 단계로 안내한다.
- 기존 로그인·라이브 대시보드의 상세 투어는 유지한다.
- 실제 업무 데이터나 저장 동작은 변경하지 않는다.
- 각 화면을 확인한 뒤 상세 단계와 실제 조작 연계를 후속 요구사항으로 보완한다.
