# 온보딩 범위 확장

## 목적

로그인과 라이브 대시보드에 한정했던 단계별 안내를 인증 후 전체 화면으로 확장한다. 공통으로 반복되는 화면 이동과 알람 알림은 각 화면 투어에서 제외하고, 현재 화면의 주요 업무 기능과 기본 사용 순서를 중심으로 안내한다.

## 대상 화면

- 화면 확대 보기
- 녹화 영상 재생
- 알람 목록
- 알림 설정
- 영상 관리
- 사용자 관리
- 공통코드 관리
- 쿼리 관리
- 모델 관리
- 기타 관리자 화면

## 초기 안내 원칙

- 도움말 아이콘을 클릭했을 때만 시작한다.
- 화면별 주요 기능을 실제 UI 영역에 연결해 여러 단계로 안내한다.
- 사용자 관리 화면은 로그인 계정 정보, 가입 신청 승인·반려, 권한 및 계정 상태 제어를 핵심으로 안내한다.
- 화면 이동과 알람 알림은 공통 기능이므로 반복 안내하지 않는다.
- 안내 문구는 한국어를 우선 제공하고 영어 전환도 지원한다.
- 기존 로그인·라이브 대시보드의 상세 투어는 유지한다.
- 실제 업무 데이터나 저장 동작은 변경하지 않는다.
- 각 화면을 확인한 뒤 상세 단계와 실제 조작 연계를 후속 요구사항으로 보완한다.
