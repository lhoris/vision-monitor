# 검증 가이드: 화면 단계별 온보딩 안내 기능

## 사전 조건

1. Node.js `24.x`와 npm `11.x`를 준비한다.
2. 저장소 루트에서 `scripts\develop.bat`로 backend와 frontend를 함께 실행한다.
3. 브라우저에서 `http://localhost:3000`에 접속한다.

## 로그인 화면 검증

1. 로그인 카드 우측 상단의 `?` 도움말 아이콘을 선택한다.
2. 사용자 ID, 비밀번호, 로그인, 회원가입 단계가 순서대로 표시되는지 확인한다.
3. 다음·이전·건너뛰기·완료가 동작하는지 확인한다.
4. 영어로 전환한 뒤 단계 제목과 설명이 영어로 표시되는지 확인한다.

## 인증 후 화면 검증

1. 로그인 후 라이브 대시보드 우측 상단 계정정보 옆의 `?` 아이콘을 선택한다.
2. 공정 선택, 영상 추가, 그리드 배치, 화면 확대, 알람 확인 단계가 표시되는지 확인한다.
3. 사용자 관리 등 미지원 화면으로 이동해 도움말 아이콘을 선택한다.
4. 온보딩 대신 안내 메시지가 표시되고 화면 조작을 막지 않는지 확인한다.

## 회귀 검증

- 온보딩 실행 중 기존 로그인, 영상 재생, 알람 목록 기능이 변경되지 않는지 확인한다.
- 브라우저 폭을 줄여 안내 팝오버와 조작 버튼이 잘리지 않는지 확인한다.
- 키보드로 도움말 버튼, 다음, 이전, 건너뛰기, 완료를 조작한다.
