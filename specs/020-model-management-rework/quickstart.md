# 모델 관리 대개편 검증 절차

## 사전 조건

- Node.js 및 frontend 의존성 설치
- 기존 프로젝트 실행 절차에 따라 frontend 개발 서버 실행
- 관리자 권한으로 로그인

## US1 대시보드 확인

1. 모델 관리 메뉴로 이동한다.
2. VM 1개와 여러 AI 프로세스가 포함된 fixture가 표시되는지 확인한다.
3. VM 상태와 프로세스 상태가 별도로 표시되는지 확인한다.
4. 실행 중, 중지, 오류, 상태 확인 불가 상태가 텍스트로 식별되는지 확인한다.

## US2 프로세스 제어 확인

1. 프로세스 카드에서 시작, 중지 또는 재시작을 선택한다.
2. 확인 절차 후 요청 중 상태가 표시되는지 확인한다.
3. 성공, 실패, 시간 초과 fixture를 각각 확인한다.

## US3 그리드 편집 확인

1. 설정 관리 보기로 이동한다.
2. 신규 프로세스를 입력하고 필수값 검증을 확인한다.
3. 저장 성공 및 저장 실패 상태를 확인한다.
4. 기존 프로세스 설정을 수정하고 대시보드에 변경값이 반영되는지 확인한다.

## US4 검색 및 필터 확인

1. VM, 공정, 프로세스 상태 조건을 적용한다.
2. 대시보드와 그리드 결과가 동일한 대상 집합을 표시하는지 확인한다.
3. 결과가 없는 조건에서 명확한 빈 상태가 표시되는지 확인한다.

## 기본 검증 명령

```powershell
Set-Location frontend
npm test -- --run
npm run build
```
