# 검증 가이드: 알람 관리 화면

## 사전 조건

- frontend 의존성이 설치되어 있어야 한다.
- mock 이벤트와 카메라 fixture가 로드되어야 한다.

## 자동 검증

```powershell
cd frontend
npm run test -- --run src/pages/__tests__/Events.test.tsx
npm run build
```

## 수동 검증

1. `/events`에 진입한다.
2. 공정, AI 모델, 판정 결과를 선택하고 `조회`를 누른다.
3. 알람 이력 행을 선택한다.
4. 우측 상세 영역에 같은 알람의 판정, 발생 시각, 위치, 녹화 영상이 표시되는지 확인한다.
5. 녹화 영상 구간이 발생 시각 기준 전후 오프셋으로 계산되는지 확인한다.
6. `받기`를 눌러 해당 오프셋 클립 다운로드 동작을 확인한다.
7. `확인`을 눌러 현재 사용자에게만 확인 상태가 반영되는지 확인한다.
8. 녹화 없음, 부분 녹화, 다운로드 실패 상태가 각각 구분되는지 확인한다.
