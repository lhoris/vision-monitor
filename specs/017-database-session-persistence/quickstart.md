# 검증 가이드: DB 세션 영속화

## 사전 조건

- MariaDB가 실행 중이고 애플리케이션 DB 접속 정보가 설정되어 있어야 한다.
- backend 의존성과 테스트 실행 환경이 준비되어 있어야 한다.

## 자동 검증

```powershell
cd backend
./mvnw test
```

확인 대상:

1. Flyway가 `TB_M26_AUTH_SESSION`을 생성한다.
2. Audit 컬럼이 먼저 존재한다.
3. FK, UK, 별도 INDEX가 생성되지 않는다.
4. 로그인으로 생성한 세션이 조회된다.
5. 만료/폐기된 세션은 조회되지 않는다.

## 재기동 검증

1. 로그인하여 브라우저에 저장된 bearer token을 확인한다.
2. 보호된 화면에 진입한다.
3. backend만 재기동한다.
4. 같은 브라우저에서 페이지를 새로고침한다.
5. 만료 전이라면 로그인 화면으로 이동하지 않는지 확인한다.

## 로그아웃 검증

1. 로그인 후 로그아웃한다.
2. 동일 token으로 보호된 API를 요청한다.
3. HTTP 401이 반환되는지 확인한다.
