# Quickstart: 화면 확대 보기 검증

## 사전 조건

```powershell
cd frontend
npm install
```

## 자동 검증

```powershell
npm test -- --run
npm run build
```

## 수동 검증 시나리오

1. `/live`를 열고 특정 공정/세부공정 탭으로 이동한다.
2. 카메라 타일에 마우스를 올리고 확대 동작으로 화면 확대 보기에 진입한다.
3. 화면 확대 보기의 카메라 전환 목록이 진입 전 그리드의 카메라 목록과 일치하는지 확인한다.
4. 실시간 모드에서 영상 영역, 제목, 온라인 상태, 메타데이터 패널을 확인한다.
5. 녹화 모드로 전환하고 타임라인, 이벤트 마커, 이벤트 목록을 확인한다.
6. 이벤트를 선택하고 URL의 `eventId`와 재생 위치/메타데이터가 갱신되는지 확인한다.
7. 테스트 알람 dialog를 열어 메시지를 입력하고 경고 토스트를 표시한다.
8. 경고 토스트를 클릭해 자연스럽게 사라지는지 확인한다.
9. 그리드에서 카메라 제목을 Rename한 뒤 화면 확대 보기에 진입해 제목이 일관되게 표시되는지 확인한다.
10. theme1, theme2, theme3로 전환해 제목, Rename dialog, 알람/경고, 녹화 타임라인/이벤트 목록의 가독성을 확인한다.
11. mock failure/forbidden fixture를 사용해 실패 영역만 fallback되고 보호 metadata가 노출되지 않는지 확인한다.
