# 참고 이미지 보관 위치

이 디렉터리는 현업/사용자가 제공한 PPT 캡처, 화면 스케치, 기존 화면 캡처를 보관한다.

현재 마이그레이션에서는 대화에 첨부된 화면 확대 보기/알람 경고 초안 이미지를 요구사항 해석 근거로 사용했지만, 원본 이미지 파일은 아직 이 디렉터리에 커밋하지 않았다.

추후 원본 PPT 캡처를 확보하면 다음 규칙으로 저장한다.

- active 자료: 현재 요구사항 해석에 사용하는 최신 화면 스케치
- superseded 자료: 더 최신 자료로 대체된 이전 화면 스케치
- deprecated 자료: 현재 요구사항 해석에는 사용하지 않고 이력으로만 남기는 초기안
