# 영상 주소 관리

기능 브랜치: `015-video-source-management`

## 개요

관리자는 카메라 추가 메뉴 대신 영상 관리 메뉴에서 라이브 모니터링에 사용할 영상 주소를 단순한 그리드로 등록하고 수정하거나 삭제한다. 이 기능은 영상 재생 상태 점검이나 녹화 설정을 포함하지 않고 주소 목록 관리에만 집중한다.

## 기능 요구사항

- FR-001: 관리자는 관리자 메뉴에서 `영상 관리` 화면에 진입할 수 있어야 한다.
- FR-002: 시스템은 영상 이름, 영상 주소, 프로토콜, 위치, 구역, 사용 상태를 목록으로 보여줘야 한다.
- FR-003: 관리자는 영상 이름, 영상 주소, 프로토콜(WebRTC/RTSP/HLS), 위치, 구역, 사용 상태를 입력해 영상을 등록할 수 있어야 한다.
- FR-004: 시스템은 영상 이름, 주소, 프로토콜이 비어 있거나 지원하지 않는 경우 저장하지 않고 오류를 보여줘야 한다.
- FR-005: 시스템은 이미 등록된 영상 주소를 다시 등록하지 않도록 안내해야 한다. 이 검증은 애플리케이션에서 수행한다.
- FR-006: 관리자는 목록의 영상을 수정하거나 삭제할 수 있어야 한다.
- FR-007: 영상 주소 관리 테이블에는 기본키 외의 데이터베이스 제약조건을 두지 않아야 한다.
- FR-008: 영상 추가와 수정 입력은 목록 그리드를 가리지 않는 모달에서 처리해야 한다.
- FR-009: 영상 목록 그리드는 사용자관리 화면과 같이 검색, 컬럼 필터, 행 선택, 복제, 일괄 삭제, 새로고침, 페이지 크기와 페이지 이동을 제공해야 한다.
- FR-010: 영상 관리 화면의 그리드는 화면의 남은 가로·세로 공간을 채워야 하며, 입력 패널 때문에 목록 영역이 불필요하게 축소되어서는 안 된다.

## 사용자 시나리오

### 영상 목록 확인

관리자가 영상 관리 메뉴에 진입하면 등록된 영상 주소가 표 형태로 보인다. 등록된 영상이 없으면 빈 상태가 표시된다.

### 영상 등록 및 수정

관리자가 입력 영역에 값을 입력하고 저장하면 목록에 새 행이 나타난다. 목록의 수정 버튼을 누르면 같은 입력 영역에서 값을 수정할 수 있다.

### 영상 삭제

관리자가 목록 행의 삭제를 선택하고 확인하면 해당 영상 주소가 목록에서 제거된다.

## 데이터

`TB_M26_VIDEO_SOURCE`는 영상 주소 하나를 한 행으로 저장한다. `VIDEO_SOURCE_ID`만 PK이며 FK, UNIQUE, CHECK 등의 제약조건은 사용하지 않는다. 중복 주소와 입력값 검증은 서비스에서 처리한다.

## 제외 범위

실제 영상 연결 상태 검사, RTSP ingest, 녹화 정책, AI 분석 설정, 라이브 그리드 배치 편집은 이번 기능에 포함하지 않는다.

## 성공 기준

- 관리자는 두 번 이내의 주요 조작으로 영상 관리 화면에 진입할 수 있다.
- 관리자는 필수값 입력 후 저장하여 목록에서 등록 결과를 확인할 수 있다.
- 중복 주소와 잘못된 입력은 저장 전에 오류로 구분된다.
- 기존 사용자관리 화면의 목록·입력·수정·삭제 흐름과 일관된 조작 경험을 제공한다.
