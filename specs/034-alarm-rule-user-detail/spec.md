# 알람 기준별 수신자 디테일 분리

## 목적

알람 기준 마스터 `TB_M26_ALARM_RULE`와 기준별 수신자·채널 디테일을 분리한다.

## 요구사항

- `TB_M26_ALARM_RULE`는 알람 코드, 알람명, 분류, 확인 방식을 관리한다.
- `TB_M26_ALARM_RULE_USER`는 알람 기준과 사용자의 조합별 수신 여부, 앱 알람, 메일, 팀즈 알림봇 수신 여부를 관리한다.
- 동일한 알람 기준과 사용자는 한 건만 등록한다.
- 새 알람 기준은 수신자 디테일을 직접 등록하기 전까지 수신자가 없다.
- 회원가입 요청 알람은 디테일이 없는 초기 상태에서도 활성 최고관리자를 기본 수신자로 사용한다.
- 기존 사용자 전역 알림 설정 테이블은 개인 알림 설정 용도로 유지한다.

## 처리 흐름

1. 알람 기준 마스터를 선택한다.
2. 선택한 `ALARM_RULE_ID`의 수신자 디테일을 조회한다.
3. 수신자와 채널을 저장하면 `TB_M26_ALARM_RULE_USER`에 저장한다.
4. 알람 요청 워커는 기준별 디테일을 읽어 수신자별 알람 로그를 생성한다.
