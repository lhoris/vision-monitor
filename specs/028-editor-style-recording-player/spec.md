# 기능 명세서: 편집기형 녹화 재생 플레이어

**기능 브랜치**: `028-editor-style-recording-player`

**작성일**: 2026-11-17

**상태**: 초안

**변경 추적**: 문서 변경 이력은 Git 커밋 이력을 기준으로 한다.

**입력**: 사용자 설명: "반디컷과 같은 방식으로 24시간 타임라인에서 녹화 구간을 선택하고, 재생 위치와 선택 범위를 마우스로 조작하는 녹화 재생 플레이어를 설계하고 구현한다."

> 이 문서는 사용자 경험과 기능 경계를 정의한다. 상세 구현은 plan.md와 contracts/에서 다룬다.

> **기능 개요 - Agent 요약**
>
> 사용자는 화면 확대 보기의 녹화 탭에서 하루 전체를 조망하는 타임라인을 기준으로 녹화 영상을 탐색한다. 현재 재생 위치와 조회할 범위를 분리해 표시하며, 범위의 양 끝 핸들과 본체를 마우스로 움직여 원하는 구간을 선택할 수 있다. 알람 marker를 선택하면 선택 범위가 알람 전후 구간으로 이동하고, 플레이어는 해당 시점부터 재생한다. 이 기능은 원본 파일을 변경하거나 저장하지 않는 비파괴 녹화 검토 기능이다.

## 2. 기능 요구사항

### 기능 요구사항

- **FR-001**: 시스템은 녹화 탭에서 선택한 날짜의 00:00부터 24:00까지 전체 시간축을 표시해야 한다.
- **FR-002**: 시스템은 전체 시간축 위에 녹화 가능 구간, 녹화 공백, 알람 marker를 구분해 표시해야 한다.
- **FR-003**: 사용자는 타임라인의 현재 재생 위치(playhead)를 마우스로 이동할 수 있어야 한다.
- **FR-004**: 사용자는 조회·재생 범위(work area)의 시작 핸들과 종료 핸들을 각각 드래그할 수 있어야 한다.
- **FR-005**: 사용자는 조회·재생 범위의 본체를 드래그해 범위 길이를 유지한 채 시간축에서 이동할 수 있어야 한다.
- **FR-006**: 시스템은 사용자가 선택한 조회 범위를 녹화 재생 요청의 시작·종료 시각으로 사용해야 한다.
- **FR-007**: 사용자가 알람 marker 또는 알람 목록을 선택하면 알람 발생 전후의 범위로 work area를 이동하고 알람 시점으로 playhead를 이동해야 한다.
- **FR-008**: 사용자는 영상 플레이어의 재생·일시정지·배속·재생바를 사용할 수 있어야 하며, 플레이어와 타임라인은 현재 위치를 동기화해야 한다.
- **FR-009**: 사용자는 날짜를 변경해 다른 날짜의 24시간 시간축을 탐색할 수 있어야 한다.
- **FR-010**: 시스템은 드래그 중에는 선택 범위를 즉시 표시하고, 범위 확정 후에만 녹화 영상을 다시 요청해야 한다.
- **FR-011**: 시스템은 잘못된 범위, 녹화 없음, 재생 실패, 요청 중 상태를 한국어로 안내해야 한다.
- **FR-012**: 이 기능은 원본 녹화 파일을 변경·삭제·저장하지 않아야 한다.

## 3. 제외 범위

- 실제 영상 파일을 자르거나 편집해 새 파일로 저장하는 기능은 제외한다.
- 다운로드, 북마크 저장, 편집 프로젝트 저장은 후속 범위로 둔다.
- 여러 카메라 트랙을 동기화하는 다중 트랙 편집기는 제외한다.
- 실제 녹화 서버의 24시간 녹화 가능 구간을 조회하는 운영 API는 이번 단계에서 추가하지 않는다. 현재 playback contract를 확장 가능한 형태로 유지한다.
- 녹화 서버 인증정보 관리와 영상 관리 화면의 녹화 경로 관리 기능은 제외한다.

## 4. UI/UX 요구사항

- **UX-001**: 플레이어 아래에 24시간 overview timeline을 배치하고, 날짜와 주요 시간 눈금을 명확히 표시한다.
- **UX-002**: work area는 선택된 구간을 강조하고 좌우 핸들을 충분히 크게 표시해 마우스로 쉽게 잡을 수 있어야 한다.
- **UX-003**: playhead는 work area와 시각적으로 구분되는 색상과 핸들로 표시한다.
- **UX-004**: 드래그 중에는 시간 tooltip을 표시하고, 드래그가 끝나면 선택 범위의 시작·종료 시간을 보여준다.
- **UX-005**: 알람 marker는 녹화 구간과 다른 색상으로 표시하며, 클릭 가능한 대상으로 인식할 수 있어야 한다.
- **UX-006**: 재생 중인 위치가 work area 밖으로 넘어가면 자동으로 다음 조회를 수행하지 않고, 범위 끝에서 일시정지하거나 종료 상태를 표시한다.
- **UX-007**: 키보드로 playhead와 work area를 조작할 수 있어야 한다. 방향키는 이동, Shift+방향키는 핸들 조작에 사용한다.

## 6. 사용자 시나리오 및 테스트

### 사용자 스토리 1 - 하루 전체에서 녹화 구간 탐색 (우선순위: P1)

운영자는 녹화 탭에서 하루 전체의 시간축을 보고, 재생 범위를 마우스로 옮겨 원하는 시간대의 영상을 조회한다.

**관련 기능 요구사항**: FR-001~FR-006, FR-008~FR-012

**이 우선순위인 이유**: 반디컷과 같은 편집기형 조작 경험의 핵심이며, 알람이 없어도 독립적으로 검증할 수 있다.

**독립 테스트**: 녹화 탭에서 work area를 이동·리사이즈하고 범위를 확정하면 start/end가 변경된 영상이 조회되는지 확인한다.

**수용 시나리오**:

1. **Given** 녹화 탭에 진입한 상태, **When** 화면을 보면, **Then** 선택 날짜의 24시간 timeline과 현재 work area가 표시된다.
2. **Given** work area가 표시된 상태, **When** 시작 핸들을 드래그하면, **Then** 시작 시각만 변경되고 종료 시각은 유지된다.
3. **Given** work area가 표시된 상태, **When** work area 본체를 드래그하면, **Then** 범위 길이는 유지된 채 전체 시간축에서 이동한다.
4. **Given** 새로운 work area, **When** 사용자가 범위 확정을 실행하면, **Then** 해당 start/end로 녹화 영상이 요청된다.
5. **Given** 플레이어가 재생 중인 상태, **When** 사용자가 playhead 또는 기본 재생바를 조작하면, **Then** 플레이어와 timeline 위치가 동기화된다.

---

### 사용자 스토리 2 - 알람 발생 구간 즉시 확인 (우선순위: P2)

운영자는 알람 marker나 알람 목록을 클릭해 알람 전후 영상으로 즉시 이동한다.

**관련 기능 요구사항**: FR-002, FR-007, FR-008, FR-011

**이 우선순위인 이유**: 알람 원인 확인을 빠르게 하지만 기본 timeline 조작 위에 구축되는 흐름이다.

**독립 테스트**: 알람 marker를 클릭하면 work area가 알람 전후로 이동하고 playhead가 알람 시점에 위치하는지 확인한다.

**수용 시나리오**:

1. **Given** timeline에 알람 marker가 표시된 상태, **When** marker를 클릭하면, **Then** 알람 전후 범위가 선택되고 해당 시점으로 playhead가 이동한다.
2. **Given** 알람 목록이 표시된 상태, **When** 알람 항목을 클릭하면, **Then** marker 클릭과 동일한 녹화 조회 흐름이 실행된다.

### 엣지 케이스

- work area 시작과 종료가 같아지거나 역전되지 않도록 최소 범위를 유지한다.
- work area가 00:00 또는 24:00 경계를 넘지 않도록 제한한다.
- 범위 이동 중 24시간 경계를 넘으면 범위를 자동으로 경계 안에 고정한다.
- 녹화 공백 구간을 클릭하면 해당 구간을 재생하지 않고 녹화 없음 안내를 표시한다.
- 외부 녹화 서버가 늦게 응답해도 최신 선택 범위의 응답만 화면에 반영한다.
- 날짜 변경 시 이전 날짜의 플레이어·marker·work area를 새 날짜와 섞지 않는다.

## 7. 성공 기준

- **SC-001**: 사용자는 시작·종료 시각을 키보드로 직접 입력하지 않고도 마우스 조작만으로 녹화 범위를 선택할 수 있다.
- **SC-002**: 사용자는 24시간 중 원하는 시점으로 3초 이내에 playhead를 이동할 수 있다.
- **SC-003**: work area의 좌우 핸들을 조작하면 시작 또는 종료 시각만 변경된다.
- **SC-004**: 알람 선택 후 2초 이내에 알람 전후 범위와 playhead가 화면에 반영된다.
- **SC-005**: 범위 확정 시 선택된 start/end가 재생 URL에 정확히 반영된다.
- **SC-006**: 기존 실시간 탭과 현재 MP4 녹화 재생의 주요 흐름이 유지된다.

## 8. 가정 및 미정 사항

### 가정

- 하루의 기준 시간대는 애플리케이션의 사용자 로컬 시간대(현재 운영 기준 Asia/Seoul)다.
- MVP의 검증 영상은 `/playback/video6.mp4`다.
- 기본 work area는 녹화 진입 시 30초이며, 사용자가 24시간 timeline에서 이동할 수 있다.
- 범위 확정은 드래그 종료 즉시 자동 조회하지 않고 명시적인 재생/조회 동작으로 확정한다.
- timeline은 브라우저에서 동작하는 전용 React 컴포넌트로 구현한다.

### 미정 사항

- 없음. 실제 녹화 availability 조회 API는 후속 연동 시 playback contract에 추가한다.
