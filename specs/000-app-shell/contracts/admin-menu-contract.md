# 계약: 관리자 메뉴

## 목적

원문 이미지의 관리자 메뉴 초안을 최신 요구사항에 맞게 재해석해, 앱 기본 뼈대가 제공해야 하는 관리자 메뉴 그룹과 하위 메뉴를 정의한다.

## 메뉴 그룹

### 통신 및 모델 수정

| 메뉴 | 의미 | 비고 |
|------|------|------|
| 모니터링 통신 현황 | 영상/모니터링 계통 통신 상태 확인 | 원문 이미지 유지 |
| 제어 연동 통신 현황 | 제어 시스템 연동 통신 상태 확인 | 원문 이미지 유지 |
| 기타 주소 설정 현황 | 외부 주소, 연동 주소, 기타 endpoint 설정 확인 | 원문 이미지 유지 |
| 모델 재가동 | 영상 모델 재가동 요청 | 원문 이미지 유지 |
| 영상 모델 추가 | 신규 영상 모델 등록 | 원문 이미지 유지 |

### 접속 권한 관리

| 메뉴 | 의미 | 비고 |
|------|------|------|
| 사용자 관리 | 사용자 계정 목록, 상태, 기본 정보 관리 | 후속 CRUD 기능 |
| 역할 관리 | 역할 목록과 역할별 설명 관리 | 후속 RBAC 기능 |
| 권한 정책 관리 | 기능/데이터 접근 권한 정책 관리 | 후속 RBAC 기능 |
| 메뉴 접근 권한 관리 | 사이드바와 관리자 메뉴 접근 가능 여부 관리 | 후속 RBAC 기능 |

## Deprecated 원문 메뉴

원문 이미지의 화면 수정 영역은 최신 sidebar 요구사항에서 제외한다.

| 원문 메뉴 | 최신 처리 |
|----------|----------|
| 공정 추가 | 002 라이브 대시보드 내부 편집 기능으로 이동 |
| 세부 공정 수정 | 002 라이브 대시보드 내부 편집 기능으로 이동 |
| 화면 배치 수정 | 002 라이브 대시보드 내부 편집 기능으로 이동 |

## 권한 영향

- 관리자 메뉴 표시 여부는 사용자 역할 또는 권한의 관리자 여부와 연결한다.
- 관리자 권한이 있는 사용자에게만 관리자 메뉴 그룹과 하위 메뉴를 표시한다.
- 관리자 권한이 없는 사용자에게는 관리자 메뉴 그룹과 하위 메뉴를 표시하지 않는다.
- 권한 정책은 후속 라이브 대시보드의 영상그리드 개인화 가능 범위에 영향을 줄 수 있다.
- 000에서는 메뉴 구조와 접근 경계만 정의하고 상세 CRUD/API는 구현하지 않는다.
