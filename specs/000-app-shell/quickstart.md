# Quickstart: 앱 기본 뼈대 검증

## 실행

```powershell
cd frontend
npm install
npm run dev
```

브라우저에서 tester 계정으로 로그인한 뒤 `/live`로 이동한다.

## 자동 검증

```powershell
cd frontend
npm test -- --run uiSlice
npm test -- --run
npm run build
```

## 수동 검증 시나리오

### 1. 보호 route와 공통 layout

1. 로그인 전 `/live`에 접근한다.
2. 로그인 후 `/live`에 접근한다.

**기대 결과**: 로그인 전에는 `/login`으로 이동하고, 로그인 후에는 상단바/본문 구조가 표시된다.

### 2. 사이드바

1. 상단바의 메뉴 버튼을 선택한다.
2. overlay와 사이드바가 표시되는지 확인한다.
3. overlay를 클릭한다.

**기대 결과**: 사이드바가 열리고 overlay 클릭으로 닫힌다.

### 3. 일반 메뉴 이동

1. 사이드바를 연다.
2. Live, Playback, Events 메뉴를 차례로 선택한다.

**기대 결과**: 각 route로 이동하고 현재 메뉴가 활성 상태로 표시된다.

### 4. 관리자 메뉴 구조

1. 사이드바를 연다.
2. 관리자 메뉴 그룹을 확인한다.
3. 통신 및 모델 수정 영역의 메뉴를 확인한다.
4. 접속 권한 관리 영역의 메뉴를 확인한다.

**기대 결과**: 모니터링 통신 현황, 제어 연동 통신 현황, 기타 주소 설정 현황, 모델 재가동, 영상 모델 추가가 보이고, 사용자 관리, 역할 관리, 권한 정책 관리, 메뉴 접근 권한 관리가 보인다. 화면 수정, 공정 추가, 세부 공정 수정, 화면 배치 수정은 sidebar에 표시되지 않는다.

### 5. 비관리자 메뉴 제한

1. `tester1 / tester123`으로 로그인한다.
2. 사이드바를 연다.

**기대 결과**: 관리자 메뉴 그룹과 모든 관리자 하위 메뉴가 표시되지 않는다.

### 6. 테마와 언어

1. 상단바에서 theme1, theme2, theme3을 전환한다.
2. 언어 메뉴에서 한국어와 영어를 전환한다.

**기대 결과**: 테마별 대비가 유지되고 navigation label 언어가 변경된다.

### 7. 로그아웃

1. 사용자 메뉴를 연다.
2. Logout을 선택한다.

**기대 결과**: 인증 상태가 해제되고 `/login`으로 이동한다.
