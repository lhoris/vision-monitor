# 검증 시나리오

1. 관리자 계정으로 로그인하고 공통코드 관리 메뉴에 진입한다.
2. 마스터 코드 `VIDEO_PROTOCOL`을 등록한다.
3. 해당 마스터를 선택하고 `HLS`, `RTSP`, `WEBRTC` 상세값을 각각 등록한다.
4. 정렬순서를 바꾸고 목록이 정렬순서대로 표시되는지 확인한다.
5. 하나의 상세값을 비활성화하고 일반 조회 결과에서 제외되는지 확인한다.
6. 로그인 직후 `GET /api/common-codes/bootstrap`이 호출되고 Redux 메모리에 코드가 적재되는지 확인한다.
7. 영상 관리 화면에서 프로토콜 선택 목록이 추가 네트워크 호출 없이 메모리 코드로 표시되는지 확인한다.
8. 로그아웃 후 공통코드 메모리가 초기화되는지 확인한다.
