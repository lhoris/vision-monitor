# 구현 계획: 반 기준 사용자·영상 관리

## 기술 방향

- 반 종류는 기존 공통코드 체계의 `USER_CLASS`로 관리하며, 반 미지정은 NULL로 저장해 전체 범위를 의미한다.
- `TB_M26_USER.CLASS_CODE`와 `TB_M26_VIDEO_SOURCE.CLASS_CODE`를 추가한다.
- 사용자 세션에 `classCode`를 포함하고, 영상 조회 서비스에서 사용자별 접근 범위를 강제한다.
- 기존 API 구조를 유지하고 응답 DTO에 반 필드를 추가한다.

## 구현 순서

1. 공통코드·사용자·영상 컬럼과 기존 데이터 보정 migration을 추가한다.
2. 백엔드 엔티티, DTO, 회원가입, 사용자 관리, 영상 목록/저장 API를 연결한다.
3. 로그인 세션과 프론트 타입을 확장한다.
4. 회원가입 모달, 사용자 관리 그리드, 영상 관리 그리드에 반을 추가한다.
5. 라이브 영상 추가 팝업에서 세션 반 기준 필터를 적용한다.
6. 관련 단위 테스트와 프론트 빌드로 검증한다.
