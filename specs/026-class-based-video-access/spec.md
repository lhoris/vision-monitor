# 기능 명세서: 반 기준 사용자·영상 관리

**기능 브랜치**: `026-class-based-video-access`
**작성일**: 2026-11-12
**상태**: 구현 준비

## 1. 목적

사용자와 영상 소스에 `반`을 지정하고, 사용자의 반에 따라 영상 목록과 라이브 화면의 영상 추가 목록을 제한한다. 반의 종류와 표시명은 공통코드로 관리한다.

## 2. 범위

- 반 공통코드 등록: 가열반, 압연반, 냉각반, 시험반, 설비반, 공통
- 회원가입 입력 화면에 반 선택 추가
- 사용자 관리 그리드와 저장 API에 반 표시·수정 지원
- 영상 관리 그리드와 저장 API에 반 표시·수정 지원
- 라이브 영상 추가 팝업의 반 필터 및 접근 범위 적용
- 로그인 세션에 사용자의 반 정보 포함

## 3. 사용자 시나리오

### US1. 회원가입 신청

가입 신청자는 반을 선택하고 신청한다. 반은 필수 입력이며, 관리자는 사용자 관리에서 신청자의 반을 확인할 수 있다.

### US2. 사용자 관리

관리자는 사용자별 반을 조회·수정할 수 있다. 반 목록은 공통코드의 활성 데이터만 사용한다.

### US3. 영상 관리

관리자는 영상 소스별 반을 지정하고 저장할 수 있다. 기존 영상은 마이그레이션 시 `공통`으로 보정한다.

### US4. 영상 추가 필터

일반 사용자는 자신의 반 영상과 공통 영상을 볼 수 있다. 반이 공통인 사용자는 전체 영상을 볼 수 있고, 팝업의 반 필터를 자유롭게 변경할 수 있다. 일반 사용자의 필터는 자동 지정되며 변경할 수 없다.

## 4. 기능 요구사항

- **FR-001**: 시스템은 `USER_CLASS` 공통코드와 5개 활성 상세값을 제공해야 한다. 반 미지정은 전체 범위를 의미한다.
- **FR-002**: 회원가입 요청은 유효한 반 코드를 포함해야 한다.
- **FR-003**: 사용자 조회·생성·수정 응답은 반 코드와 표시명을 제공해야 한다.
- **FR-004**: 영상 조회·생성·수정 응답은 영상의 반 코드를 제공해야 한다.
- **FR-005**: 영상 목록 API는 요청 사용자의 반을 기준으로 접근 가능한 영상만 반환해야 한다.
- **FR-006**: 공통 사용자는 전체 영상 목록을 조회할 수 있어야 한다.
- **FR-007**: 일반 사용자는 자신의 반 및 공통 영상만 조회할 수 있어야 한다.
- **FR-008**: 프론트엔드의 반 필터 잠금은 편의 기능이며, 접근 제한은 백엔드에서도 강제해야 한다.
- **FR-009**: 기존 영상과 기존 사용자의 반이 비어 있으면 공통으로 처리해야 한다.

## 5. 제외 범위

- 한 영상을 여러 반에 매핑하는 다대다 태그 구조
- 반별 별도 권한·승인 체계
- 반별 영상 편집 권한 분리

## 6. 성공 기준

- 회원가입부터 사용자 관리, 영상 관리, 라이브 영상 추가까지 동일한 공통코드가 사용된다.
- 일반 사용자는 다른 반 영상이 API 응답과 팝업 목록에서 노출되지 않는다.
- 공통 사용자는 전체 영상 목록을 확인하고 반 필터를 변경할 수 있다.
- 기존 데이터는 별도 수동 수정 없이 공통으로 조회된다.
