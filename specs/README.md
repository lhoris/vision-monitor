# Spec Kit 기능 번호 계획

이 디렉터리는 Spec Kit 기능 산출물을 기능 번호 순서로 관리한다.

## 예정 번호

| 번호 | 기능 | 상태 |
|------|------|------|
| 000 | 앱 기본 뼈대: 상단바, 사이드바, 공통 레이아웃, 메뉴 구성 | 작성됨 |
| 001 | 로그인 기능 | 작성됨 |
| 002 | 라이브 메인 화면: 공정탭, 세부공정, 영상 그리드 | 작성됨 |
| 003 | 화면 확대 보기: 특정 CCTV 영상 1개와 메타데이터 패널 | 작성됨 |

기능 번호는 사용자-facing 기능 흐름 기준으로 부여한다. 기존 번호를 변경할 때는 `.specify/feature.json`, 관련 spec 문서, migration 문서, 검증 스크립트의 경로 참조를 함께 갱신한다.
